# Features

CS2 Config Workspace / Config Hub connects the language tools to a user-selected folder. The Home follows the supplied visual reference with native VS Code sidebar navigation and a responsive, theme-aware WebView.

| Feature                                                                   | Status                                                                 |
| ------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Activity Bar with Workspace, Config Files and Tools                       | Implemented                                                            |
| Home, folder identity, quick actions and per-file overview                | Implemented                                                            |
| Manual selection, Steam library detection, folder consent and persistence | Implemented; Windows integration verified, other platforms need review |
| Open CFG, read-only Visual Bind Map and Health Check                      | Implemented using existing domain services                             |
| New empty CFG with destination review and exclusive creation              | Implemented                                                            |
| Text editing, command documentation, checking and formatting              | Implemented in the editor                                              |
| Autoexec / Practice / Alias builders and Command Explorer panel           | Planned cards; no registered builder commands                          |
| Visual bind editing, generated previews and source-preserving writes      | Planned                                                                |
| Cross-file exec resolution and effective workspace state                  | Planned; current summaries are independent single-file results         |

Use the [English guide](docs/user-guide.md#config-hub) or [guia em português](docs/user-guide.pt-BR.md#hub-de-configurações) for access, behavior and limits. Features under development are recorded in [Unreleased](CHANGELOG.md#unreleased); distribution requires a separate request.
