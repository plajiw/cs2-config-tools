# CS2 Config Tools

Write, understand and organize Counter-Strike 2 CFG files in VS Code.

## What it offers

- **Command Explorer:** search command names or descriptions, read shared documentation and copy a command name from the Hub.
- **Saved video settings:** connect a Steam userdata folder and inspect resolution, aspect ratio, refresh rate and literal video values with direct access to the text editor for manual changes.
- **Config hub:** connect a CFG folder, browse your CFGs, expand other detected CFGs and open the bind map or health report from one Home screen with only implemented tools. Includes one connection flow for the game folder and Steam profile, safe creation of empty CFGs and confirmed CFG removal to Trash.
- **Command checking:** spot unknown names, unfinished quotes and values outside documented types, choices or ranges.
- **Bind health checks:** identify repeated key bindings and replacements, with links to the previous binding and relevant local alias definitions.
- **Visual bind map:** inspect keyboard, mouse and numpad binds, review literal actions and jump to their source or previous bindings. Dedicated keyboard/mouse sections and an inspector below keep the layout readable across panel sizes. Supports keyboard navigation, keeps focus during updates and identifies uncertain results.
- **CFG health report:** review findings grouped by category, severity totals, source lines and explained analysis limits in the Output panel.
- **Documentation on hover:** see a command's purpose, the value written in your CFG, known defaults and ranges, and meanings for choices such as HUD colors.
- **Autocomplete and quick fixes:** find commands and known values while typing, then select suggestions to correct nearby command names.
- **CFG formatting:** organize spaces, blank lines and section separators while preserving command order and quoted content.
- **Navigation:** jump to local aliases or files referenced by exec, find local alias references and browse definitions in the editor outline.
- **Optional value hints:** display reviewed parameter meanings beside values, using your preferred description language.
